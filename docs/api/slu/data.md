## SLU data and constants (`src/slu/datareader.py`)

Constants
- `y1_set = ["O", "B", "I"]`
- `y2_set`: 72 BIO-tagged slot labels.
- `domain_set`: 7 domains used in SNIPS: AddToPlaylist, BookRestaurant, GetWeather, PlayMusic, RateBook, SearchCreativeWork, SearchScreeningEvent
- Indices: `SLOT_PAD=0`, `PAD_INDEX=0`, `UNK_INDEX=1`

Classes
- `Vocab`: simple word-index vocabulary with `index_words`, `n_words`, `word2index`, etc.

Functions
- `read_file(filepath, vocab, use_label_encoder, domain=None)` → tuple `(data_dict, vocab)` where `data_dict` has keys `utter`, `y1`, `y2`, and optionally `template_list` (three template variants per sample when TR is enabled)
- `binarize_data(data, vocab, dm, use_label_encoder)` → integer-indexed sequences and labels; adds `domains` with domain index
- `datareader(use_label_encoder=False)` → returns dict mapping domain→binarized data, and a shared `Vocab`

Notes
- When `use_label_encoder=True` (template regularization), templates are generated by replacing B- tags with slot names and two negative alternatives.
